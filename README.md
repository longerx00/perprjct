# Перцептрон

Лабораторная А1.

## Что делает программа

Перцептрон на numpy, который делит точки на два класса. Программа генерирует два облака точек, обучает на них перцептрон и выводит точность, потом делает то же самое на датасете iris. Графики сохраняются в папку `plots`.

- `perceptron_lab/model.py` - класс `Perceptron`: `activate` (ступенька), `predict` (считает z и выдаёт 0 или 1), `train` (обучение по эпохам, правило `w += lr * (target - pred) * x`), `score` (доля правильных ответов).
- `perceptron_lab/data.py` - генерирую два облака точек вокруг (-1, -1) и (1, 1), загружаю iris (только setosa и versicolor, два признака) и делю данные на train и test.
- `perceptron_lab/plots.py` - рисую точки двух классов с границей решения и график ошибок по эпохам.
- `perceptron_lab/cli.py` - читаю аргументы из терминала, обучаю перцептрон на облаках и на iris, вывожу точность и сохраняю графики.
- `perceptron.py` - запуск программы.
- `tests/test_perceptron.py` - тесты.

## Как запустить

```bash
uv run python perceptron.py --samples 200 --lr 0.1 --epochs 50
```

`--samples` - число точек, `--lr` - скорость обучения, `--epochs` - максимум эпох. Если их не указать, будут 200, 0.1 и 50.

## Как тестировать

```bash
uv run pytest
```

Тесты проверяют ступеньку, длину весов, `predict`, что после обучения точность 1.0 на облаках и на iris, и что при неправильном `--lr` программа пишет понятную ошибку.
